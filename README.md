# Power-BI

Olá, seja muito bem vindo (a) ao mundo Power BI (PBI). Aqui você irá encontrar alguns trabalho desenvolvidos com muita técnica de modelagem, DAX, Power Query, Storytelling, mas com foco na clareza para decidir. BI não é sobre gráficos bonitos, é reduzir tempo de análise, direcionar foco para ação, apoiar decisões estratégicas.
